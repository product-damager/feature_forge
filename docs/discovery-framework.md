# Discovery Framework

## 1. Purpose

This framework defines how product ideas are generated, evaluated, and structured.

---

## 2. Idea Generation Sources

Ideas must come from:

- user workflow friction
- competitor feature gaps
- internal product limitations
- analytics / drop-off points
- support / sales feedback

---

## 3. Evaluation Criteria

Each idea is evaluated on:

### 3.1 User Value
Does it solve a real workflow problem?

### 3.2 Product Fit
Does it fit Kameleoon’s mental model?

### 3.3 Technical Feasibility
Can it be built incrementally?

### 3.4 Strategic Impact
Does it improve activation, retention, or expansion?

---

## 4. Benchmarking Method

For each idea:
- identify competitor equivalents
- extract UX patterns
- identify gaps vs Kameleoon
- adapt, do not copy

---

## 5. Output Format Standard

Every analysis must include:

- Problem
- Insight
- Competitor approach
- Opportunity
- Proposed solution
- Risks
