Global Parameters — prototypes

Two product directions, both built and inside Settings: a simple shared-value dashboard, and a parameter-first variant.

Direction 1 · ready

Dashboard MVP (Settings)

A Settings dashboard of shared values. Change a value once and every flag that uses it receives the update.

 Direction 2 · ready

Parameter-first (Settings)

The parameter is the primary object, decoupled from code. Its value is a static literal or sourced from a Feature Flag variable (project- and type-matched) — re-source it centrally with no code change.
